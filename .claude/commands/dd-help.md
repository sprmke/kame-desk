# dd-help

Show **DoctorDesk teammate commands** (`/dd-*`).

| Command                   | Use when…                        |
| ------------------------- | -------------------------------- |
| **/dd-help**              | This list                        |
| **/dd-create-new-ticket** | File a GitHub issue              |
| **/dd-start-work**        | Branch for issue #N              |
| **/dd-pull-new-changes**  | Pull latest `main`               |
| **/dd-start-app**         | Run local stack (`pnpm run dev`) |
| **/dd-check-before-pr**   | `pnpm run ci:quality`            |
| **/dd-design-review**     | Anti-slop review of a route/diff |
| **/dd-submit-for-review** | Push + open PR                   |

Also: `/self-review`, `/github-issue`, `/fix-merge-conflicts`, `/workflow-*`, `/superpowers-*`.

Docs: `docs/phases/README.md`, `docs/guides/routes/README.md`. Prod unlock: **deskwave**.
