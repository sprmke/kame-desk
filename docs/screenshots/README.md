# Screenshots

Portfolio images for the main [README](../../README.md).

Capture with the local stack running:

```bash
pnpm run dev
pnpm run capture:design-screenshots
```

| File (planned)        | View                       |
| --------------------- | -------------------------- |
| `login.png`           | Staff sign-in              |
| `dashboard.png`       | Today / dashboard overview |
| `calendar.png`        | Appointment calendar       |
| `waiting-room.png`    | Live waiting room board    |
| `patient-chart.png`   | Patient detail / timeline  |
| `soap-editor.png`     | SOAP note editor           |
| `billing-invoice.png` | Invoice detail             |
| `assistant.png`       | AI Clinic Assistant panel  |

Recommended width in README: **900px** for full-page views, **700–900px** for in-app panels.
